# 词星球 · 小学英语单词乐园

面向小学三至六年级的响应式英语单词 PWA，手机、平板和电脑都可直接使用。包含音标、英式/美式设备语音、看图记忆、连续学习、拼写、跟读回放、五种游戏、错词复习和 A4 默写纸。

## 直接使用

- 在线版：<https://xrenyan.github.io/word-planet/>
- Windows 便携版：从 [Releases](../../releases/latest) 下载（保留原有发布，不被网页版替换）。

首次联网打开后，主要页面与八册词表会被缓存；学习记录保存在当前浏览器。不同设备之间不会虚构同步。

## 内容与来源说明

- 当前静态包包含三至六年级上下册共八册、1175 个公开来源匹配词，部署时不会依赖私人电脑或局域网接口。
- 词表不是外研社官方逐词认证数据，软件会如实显示来源和复核状态。
- 945 个不重复词随站提供英式、美式两套合成语音（共 1890 个 MP3），不冒充真人录音；文件异常时才回退到设备的 `en-GB` / `en-US` 系统语音。
- 原来源图片需要联网；来源不可用时自动显示本地词义记忆卡，不留下空白图片。
- 跟读仅在当前页面本地录音和回放，不伪造 AI 评分。
- 网页版学习记录只保存在当前浏览器，可在工具箱导出或清除。
