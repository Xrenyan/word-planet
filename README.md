# 词星球 · 小学英语单词乐园

面向小学三至六年级的响应式英语单词 PWA，手机、平板和电脑都可使用。包含参考音标、英美合成语音、词义配图、每组最多8词的连续学习、拼写、跟读回放、五种游戏、间隔复习、A4默写纸和可选加密备份。

## 直接使用

- 在线版：<https://xrenyan.github.io/word-planet/>
- Windows 便携版：从 [Releases](../../releases/latest) 下载（保留原有发布，不被网页版替换）。

首次联网打开后，主要页面与八册词表会被缓存。音频按使用缓存，首次播放仍需网络。学习记录默认保存在当前浏览器；工具箱可自行同意并创建加密备份，通过私密配对码在另一设备手动合并。不会默认上传，不需要姓名、邮箱或账号，录音不上传。重要记录建议另存JSON导出文件。

## 内容与来源说明

- 当前静态包包含三至六年级上下册共八册、1195个词，不依赖私人电脑或局域网接口。
- 四年级原上册入口已替换成用户照片第82–85页的165词，Unit 1–6分别31/40/27/19/26/22词。照片未显示版权页，不能确认出版年份与印次。没有另建重复册次。
- 四上164/165项有可追溯英美音标；because of sb / sth 是带占位符的教材写法，暂缺完整可核对音标。三年级来源标注新版；四下、五六年级仍是旧版Module来源，不能声称已接齐全套最新教材。
- 词表不是外研社官方逐词认证数据，软件会如实显示来源和复核状态。
- 963个不重复词随站提供英美合成语音，另有过去式read的上下文专用音频；不冒充教材原声或真人录音。支持慢速播放、下一词预加载，异常时才尝试对应口音的系统语音。
- 本地OpenMoji配图保留作者与CC BY-SA 4.0声明；既有第三方词义图仍需联网且权利归原来源。四上94/165项有来源图，未完成所有图片目视核验；无图时显示明确的词义提示，不用泛用示例图假装精确插图。测试模式不会展示可能含英文答案的远程图。
- 跟读仅在当前页面本地录音和回放，不伪造 AI 评分。
- 错词立即巩固，记住后的复习间隔为1/3/7/14/30天；即时重复不会被算成长期记忆证明。不是Anki FSRS或AI掌握度评测。
- 加密备份采用浏览器AES-GCM和独立派生的认证密钥，服务器只保存密文；配对码等同密码，丢失无法找回。180天未更新的备份失效。服务有容量和频率上限，不承诺企业SLA；离线导入导出始终保留。

## 本地开发与验证

```bash
npm ci
npm test -- --run
npm run test:resources
npm run build
npm run test:e2e
```

`main` 分支通过 GitHub Actions 自动发布到独立的 GitHub Pages 站点，不会修改 `rulequant-terminal` 或 `rulequant-terminal-pages`。

后端部署配置与迁移位于 `backend/`。`scripts/verify-live-sync.mjs` 仅用临时合成记录测试线上读写、冲突保护与拒绝错误密钥，最后删除测试备份。后端上线不代表所有手机、微信内置浏览器、打印机或网络条件都已实机验收。
