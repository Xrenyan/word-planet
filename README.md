# 词星球 · 小学英语单词学习

词星球是一套面向小学三至六年级的英语单词学习工具，提供音标、英式/美式离线合成语音、看图记忆、拼写练习、跟读、游戏和 A4 默写纸。

## 下载

请从 [Releases](../../releases/latest) 下载最新版 `词星球-Windows免安装版.zip`。

## 使用方法

1. 下载压缩包并完整解压，不能在压缩软件预览窗口中直接运行。
2. 打开解压后的 `WordPlanet-Portable` 文件夹。
3. 双击 `启动词星球.cmd`。
4. 不再使用时，可以双击 `停止词星球.cmd`。

支持 Windows 10/11 64 位。手机和平板不能直接运行 Windows 压缩包；如果同一网络内有一台 Windows 电脑正在运行词星球，可以使用启动器显示的局域网地址从移动设备访问。

## 内容与来源说明

- 当前包含三至六年级八册、1175 个公开来源匹配词。
- 词表不是外研社官方逐词认证数据，软件会如实显示来源和复核状态。
- 英式、美式发音为随包提供的本地离线合成语音，不冒充真人录音。
- 原来源图片需要联网；来源不可用时自动显示本地词义记忆卡，不留下空白图片。
- 学习记录只保存在用户解压目录下的 `data` 文件夹中。

## 文件校验

Release 同时提供 SHA-256 校验文件。下载后可以在 PowerShell 中执行：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\词星球-Windows免安装版.zip'
```
